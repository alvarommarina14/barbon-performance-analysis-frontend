# docs

This directory holds one document: `barbon-performance-analysis-mockup-v3.html`, the no-code
mockup the product was validated as. It is the specification for both UX and copy — open it
alongside the app when building a screen, and match it rather than approximating it.

The architecture, the data model, the phase plan and the ADRs live in the
`barbon-performance-analysis-backend` repository under `docs/`. They are deliberately not copied
here: one home per document, so the two repositories cannot drift apart.
